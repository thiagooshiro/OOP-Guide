# Recipe Browser - Três Abordagens

Três versões do mesmo aplicativo de receitas, organizadas para demonstrar diferentes paradigmas de código.

## Versões

| Pasta | Abordagem | Objetivo |
|-------|-----------|----------|
| [functional-example/](./functional-example/README.md) | Funcional (sem classes) | Referência de código simples que funciona |
| [hybrid-starter/](./hybrid-starter/README.md) | Híbrida (com desafio) | Exercício: implementar a classe MealCard |
| [full-class-example/](./full-class-example/README.md) | Orientação a objetos completa | Referência de arquitetura pesada (similar ao Projeto 11) |

## Ordem sugerida

1. Comece pelo `functional-example/` para entender o app
2. Depois vá para o `hybrid-starter/` e faça o desafio
3. Por fim, explore o `full-class-example/` como referência
